# 旅游相机 · 带海拔

单文件 H5 网页应用：拍照 / 相册导入自动烧录**实时海拔 + 地址 + 时间**水印。
（注：本仓库是 H5 网页，不是微信小程序本体；可部署为 HTTPS 链接在微信内打开，或用 web-view 嵌进小程序壳。）

## 功能
- 实时海拔仪表：高精定位 + Open-Meteo 查海拔（Open-Elevation 兜底）+ BigDataCloud 逆地理出地址
- 相机叠加拍照加印：调用摄像头实时预览、拍照后旋转校正 + 裁剪 + Canvas 烧水印
- 相册导入加印：自写 EXIF + XMP 双解析拿 GPS/拍摄时间（华为/苹果 GPS 常在 XMP），查海拔后烧同款水印
- **系统原生相机**：调用系统相机 App 拍照，所有镜头能力由系统决定
- **离线手动编辑**：无信号时手工填海拔 / 地址 / 时间 / 经纬度，直接写进水印
- **付费墙**：免费试用 5 次，¥19.9 永久解锁（激活码校验，后端对接见下）

## 隐私
仅使用只读 GET 请求查询海拔/地址，无密钥上传，无用户数据外发。

## 本地预览
直接用浏览器打开 `index.html` 即可（定位/摄像头需 HTTPS 或 localhost）。

## 部署（永久 · 免费）
1. 把本仓库连到 Vercel：Vercel 导入 `iambuluo/travel-camera` → Deploy，得到 `*.vercel.app` 永久链接
2. 之后 push 到 `main` 分支，Vercel 自动重新部署
